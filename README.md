### 👨‍💻 关于我 (About Me)

我是一名专注于移动端架构与跨端工程的 **Android 研发工程师**，同时也是活跃的开源与 AI 工具链探索者。

- 📱 **移动端深耕**：专注于 Android 性能优化、组件化架构演进、现代 Kotlin 协程/Flow 响应式编程与混合容器技术。
- 🦀 **全栈与系统探索**：拓展 Rust / Tauri 跨平台桌面端应用开发，追求高可靠性与极致性能。
- 🤖 **AI 提效实践**：深度拥抱 AI Agent 协同编程，构建基于 LLM 的工程化提效工具链。
- ✍️ **知识沉淀与分享**：在 CSDN 等社区持续输出深度技术文章，坚信技术分享与交流是共同成长的最好催化剂。
